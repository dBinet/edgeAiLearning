Summary of what I learned so far:

Supervised learning:
    Supervised learning is the most used right now. The idea behind supervised learning is that the training set (data used to train the model) 
    contains both the input and also the output. So you're telling the model that for input x you should get output y. There is subclassification
    in supervised learning. There is regression, where the output is a number. For example, predicting the selling price of a home based on one or
    multiple parameters. The second common alogirthm is classification, where you're trying to determine if, based on input, it belongs to a specific class
    For example, trying to identify cancer on a X-RAY. It's ether has cancer or not. Trying to identify if it's a dog in a picture or a cat. If an email
    is a scam or not, etc.

Unsupervised learning:
    Unsupervised learning differ from supervised learning in the training set provided to traing the model. In unsupervised, you don't provide what the output
    is based on the input. One usecase, is clustering where you let the algorithm trying to identify group/pattern in the data. For example, grouping customer
    based on what was bought. Another usecase is anomaly detection, where the model try to identify outliers in the data. For example for fraud detection. There 
    are other models but those 2 are the most common

Thoughts:
    I think unsupervised learning has more potential to identify discover new patterns that would have been missed otherwise. But it seems to me that 
    unsupervised might be more difficult to run on low end hardware that are more commonly found at the edge of the network. So supervised learning might
    be best suited for now to run on edge devices compared to unsupervised learning. It is still unclear to me how I can integrate my different experience
    to become an interesting candidate but I'm still at the beginning of my journey.
